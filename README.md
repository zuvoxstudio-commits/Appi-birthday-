# Birthday Surprise Website ❤️

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
   - the `assets` folder
3. Keep the filenames exactly as they are.
4. Open the repository's **Settings → Pages**.
5. Under the build/deployment option, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will give you a Pages link. Send that link to your Appi.

## Assets

- `assets/Appipic.jpg` = uploaded photo
- `assets/Music.mp3` = uploaded song

## Add more photos later

Put more images inside `assets/` and add extra `<img>` cards in `index.html`.

Note: Most mobile browsers block autoplay. The website intentionally starts the music after the first button tap.
